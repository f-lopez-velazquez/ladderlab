# Referencias de terceros

## SimulIDE

El flujo de trabajo del apartado **General** —seleccionar componentes, colocarlos, conectarlos y energizar el circuito— está inspirado conceptualmente en [SimulIDE](https://github.com/Arcachofo/SimulIDE-dev), creado por Santiago González y su comunidad.

SimulIDE se distribuye bajo GNU AGPL v3 y contiene contribuciones bajo GNU GPL v3. LadderLab no incorpora, traduce, compila ni redistribuye su código fuente, recursos o ejecutables. El simulador web de LadderLab es una implementación independiente escrita en React y JavaScript y permanece bajo la licencia MIT de este repositorio.
